# Разработка модов

Папка мода называется по его идентификатору. В `mod-id.json` укажи `id`, отображаемое `name`, число `api` со значением 1 и путь `script`, например `script/main.js`. Этот файл загружается как JavaScript-модуль в окне игры. Относительные импорты должны лежать внутри папки `script/`.

Папка `games/<релиз>/amicur.set/mods/` подходит для мода одной версии. Папка `data-launcher/plugins/defold-modpack/mods/` подходит для мода, доступного нескольким версиям. Включи мод отдельно для каждого релиза из интерфейса лаунчера.

У каждого релиза каталог локализации находится в `amicur.set/mods/multilanguage-mod/local/original-source/`. Используй поле `hash` из каталога как `sourceHash` в файле перевода. Поле `text` содержит переведённую строку.

## Настройки модов

Добавь папку мода в `data-launcher/plugins/defold-modpack/mods/`, `games/<релиз>/mods/` или `games/<релиз>/amicur.set/mods/`. Во вкладке «Моды» выбери релиз слева. Галочка включает мод. Нажатие на название открывает настройки. Кнопка «Применить» сохраняет выбранные значения для этого релиза.

Мод объявляет поля в объекте `settings` файла `mod-id.json`. У каждого поля должны быть `type` и `default`. Допустимые типы `boolean`, `string`, `number`, `choice`. Подпись задаётся через `label`. Для `choice` добавь объект `choices`, где ключи задают значения, а строки задают подписи вариантов. Скрипт читает настройки через `await window.amicur.modSettings("id-мода")`.

## Своя тема

Создай папку `data-launcher/theme/<имя>`. Имя папки может содержать латинские буквы, цифры, дефис и подчёркивание. Положи туда `theme.json` и изображения.

```json
{
  "name": "Моя комната",
  "tone": "dark",
  "colours": { "back": "#282132", "accent": "#94bbe9", "on-accent": "#191420" },
  "backgrounds": [
    { "from": "06:00", "to": "18:00", "image": "images/day.png" },
    { "from": "18:00", "to": "06:00", "image": "images/night.png" }
  ]
}
```

Расписание использует местное время компьютера. Начало интервала включено, конец исключён. Интервал может переходить через полночь. Одинаковые начало и конец означают фон на весь день. При пересечении используется первая запись. Перезапусти лаунчер и выбери тему в настройках.

## Язык мода и комплект версии

Пиши исходные строки, имена и описания модов по-английски. В `local/en-US/strings.json` хранится английский словарь, в `local/ru-RU/strings.json` и соседних каталогах - переводы. Формат словаря: `{"Open journal": "Открыть дневник"}`. Для имени и описания в менеджере есть ключи `mod.name` и `mod.description`. Подписи полей и вариантов можно переводить по их английскому тексту.

Обозначь корень интерфейса мода атрибутом `data-amicur-mod="my-mod"`. Модлоадер переключает его текст при смене языка. Для динамических строк и атрибутов получай словарь через `await window.amicur.modLocale("my-mod")`, используй `strings[key] ?? englishText` и обновляй интерфейс через `window.amicur.subscribe(callback)`. Исходный английский обязателен и для сторонних скриптов. При отсутствии перевода действует английский. Без активного `multilanguage-mod` язык игры и модов - английский.

Лаунчер обнаруживает плагины по `data-launcher/plugins/<id>/plugin.json`. Декларативный плагин типа `modpack` указывает `id`, `api: 1`, `type: "modpack"` и `enabled`. Встроенный `defold-modpack` копирует содержимое своей папки `mods/` в каждую версию. Реестр `amicur.set/modpacks.json` позволяет удалить установленный мод из конкретной сборки. Настройки запуска этой версии лежат в `launcher.json`, ID профиля, выбранный язык и настройки модов - в `profile.json` внутри `amicur.set`.
