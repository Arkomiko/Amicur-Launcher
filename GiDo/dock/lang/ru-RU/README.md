# Amicur Launcher

Запусти `Amicur_Launcher.exe` в папке, доступной для записи. При первом запуске мастер предложит выбрать язык, оформление и настройки обновлений.

В разделе «Игры» можно проверить выход нового релиза или открыть папку `games/`. Для ручного добавления распакуй каждый релиз в отдельную папку с `index.html` внутри. Имя папки произвольное.

В разделе «Моды» выбери релиз, настрой язык игры и включи нужные моды. Окна каждой игры запускаются отдельно.

Стрелка рядом с «Играть» открывает команды для выбранной версии. «Запустить без модов» действует один раз. «Обновить» проверяет itch.io и добавляет новый официальный релиз отдельной папкой. «Удалить» перемещает папку выбранной версии в корзину после подтверждения.

На вкладке «Моды» перетащи папку мода или ZIP. Выбери установку для одного релиза или для всех. После установки включи мод для нужной версии и нажми «Применить». При ошибке открой отчёт на этой вкладке и скопируй его для автора.

Автор мода может указать в `mod-id.json` массивы `tested` (проверенные номера версий игры), `requires` (ID обязательных модов), `conflicts` (несовместимые ID) и строку `version`. Пример: `"tested": ["0.35"], "requires": ["multisaved-mod"]`. Зависимости загружаются первыми. Непроверенная версия допускает запуск.

Встроенные моды «История реплик», «Быстрые сохранения» и «Закладки сцен» включаются отдельно. Все три доступны в меню сохранений игры. Alt+H открывает историю текущего сеанса, Alt+B открывает закладки. F5 создаёт быстрое сохранение, F9 загружает последнее. У каждой версии свои закладки и три быстрых слота.

Файлы общих сохранений лежат в `data-launcher/saves/shared/`.
